# Screen-Time-and-Mental-Health-A-Data-Driven-Study

A machine learning project exploring the relationships between digital device usage, sleep, stress, mental wellness, and productivity.

## Overview

This project investigates how digital behavior and lifestyle factors are associated with productivity, stress, and mental wellness.

## Objectives

The project focuses on:

- **Productivity Prediction** — Predict productivity scores using digital activity, lifestyle, and mental-wellness indicators.
- **Stress Modeling** — Model stress levels using screen time, sleep, exercise, social activity, and related behavioral factors.
- **Behavioral Clustering** — Identify behavioral profiles based on digital usage and lifestyle patterns.
- **Correlation & Feature Engineering** — Explore relationships among screen time, sleep, stress, productivity, and mental wellness.

## Dataset

The dataset contains behavioral, lifestyle, and well-being information, including:

- Age and gender
- Occupation and work mode
- Total screen time
- Work-related screen time
- Leisure screen time
- Sleep duration and sleep quality
- Stress level
- Productivity score
- Exercise duration
- Social activity
- Mental wellness

## Methodology

### Exploratory Data Analysis

Exploration of distributions and relationships among screen time, sleep, stress, productivity, and mental wellness using statistical analysis and visualization.

### Productivity Prediction

Productivity is formulated as a regression problem.

Models explored include:

- Linear Regression
- SGD Regressor
- Random Forest Regressor
- Gradient Boosting Regressor

### Stress Modeling

Stress is modeled using behavioral and lifestyle variables including screen time, sleep duration, exercise, and social activity.

### Behavioral Clustering

Unsupervised learning is used to investigate behavioral profiles using:

- K-Means
- DBSCAN
- PCA
- t-SNE

## Key Findings

The analysis identified relationships between digital behavior, lifestyle factors, mental wellness, stress, and productivity.

The predictive modeling experiments showed that machine learning models can capture meaningful variation in productivity and stress-related outcomes. The clustering analysis also revealed distinct behavioral patterns across users.
